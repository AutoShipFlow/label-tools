# Agent Notes for label-tools

Before editing content in this repository, read:

- `CONTRIBUTING-CONTENT.md`

This repository is a public knowledge base and free online tool directory for label PDF, thermal label printing, barcode label, and ecommerce shipping label workflows.

It does not contain AutoShipFlow application source code.

Use `docs/` for solved problems with stable explanations and matching AutoShipFlow tool workflows.

Use GitHub issues for open-ended case collection topics that need more user examples, file patterns, printer models, or workflow details.

Keep English and Simplified Chinese content paired where practical:

- `README.md` / `README.zh-CN.md`
- `docs/en/...` / `docs/zh-CN/...`
