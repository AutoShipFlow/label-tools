# Shipping Label Prints on Two Pages

[简体中文](../../../zh-CN/label-printing/label-prints-on-two-pages.md)

## Problem

A single shipping label prints across two sheets, or the label is too large for the selected thermal label paper. The barcode or address may be cut off.

## Common Causes

- The PDF page is larger than the selected printer paper.
- The print dialog uses the wrong paper size.
- The label content is not fitted to the target label page.
- The file was exported for a different label format.

## How to Fix It

Use [Label Printing AI](https://www.autoshipflow.com/tools/label-printing-ai):

1. Upload the label PDF.
2. Choose the real paper size, such as 4 x 6 in or 100 x 150 mm.
3. Describe the issue, such as `the label prints on two pages`.
4. Preview the fixed PDF and confirm one complete label appears on each page.
5. Print with the same paper size and 100% / Actual size scale.

## What the Tool Can and Cannot Fix

The tool can generate a PDF where each label is fitted onto one target page.

It cannot force your printer to use the correct paper size. If the browser print preview still shows two pages, go back and check the target paper size. If the preview is correct but physical printing is not, check printer settings.
