# 裁掉物流标签 PDF 的多余空白

[English](../../../en/label-printing/crop-blank-space-from-label-pdf.md)

## 问题现象

标签内容位于一个很大的空白 PDF 页面里。打印时，打印机会缩放整个页面，导致真正有用的标签区域变得很小。

## 常见原因

- 平台把标签导出到了 A4 或 Letter 页面上。
- 标签内容周围有大量白边。
- PDF 页面尺寸看似正常，但可视标签内容明显偏小。
- 打印机按整页缩放，而不是按标签内容缩放。

## 如何处理

如果你是为了解决打印尺寸问题，使用 [标签打印 AI](https://www.autoshipflow.com/zh-cn/tools/label-printing-ai)。如果只是想直接裁白边，使用 [标签裁白边](https://www.autoshipflow.com/zh-cn/tools/crop-label)：

1. 上传标签 PDF。
2. 选择目标标签纸尺寸。
3. 描述问题，例如：`裁掉标签周围多余空白`。
4. 检查预览里条码和文字是否完整。
5. 打印或下载处理后的 PDF。

## 工具能解决什么，不能解决什么

工具可以安全裁掉多余空白，生成更适合打印的 PDF。

但不能盲目贴着条码、地址或承运商标识裁切。批量打印前，请先检查预览。
