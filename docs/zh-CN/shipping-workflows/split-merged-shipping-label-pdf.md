# 拆分合并的物流标签 PDF

[English](../../../en/shipping-workflows/split-merged-shipping-label-pdf.md)

## 问题现象

平台把很多物流标签导出成一个多页 PDF。你需要一页一个文件，用于打印、分享、分配给仓库人员或逐页检查。

## 常见原因

- 订单平台和打单系统经常把多张面单合并成一个 PDF。
- 有些仓库流程要求每票货对应一个单独标签文件。
- 合并 PDF 不方便单独发送、补打或逐页核对。
- 有时只需要拆成单页文件，不需要按跟踪号命名。

## 如何处理

使用 [标签 PDF 拆分](https://www.autoshipflow.com/zh-cn/tools/split-label)：

1. 上传合并的物流标签 PDF。
2. 把 PDF 拆成一页一个文件。
3. 下载 ZIP 压缩包。
4. 如果需要按跟踪号命名文件，请使用面单重命名。

## 工具能解决什么，不能解决什么

工具可以把合并 PDF 拆成单页标签文件。

它不会按跟踪号重命名文件。如果需要跟踪号文件名，请使用面单重命名。
